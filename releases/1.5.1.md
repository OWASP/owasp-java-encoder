# OWASP Java Encoder 1.5.1

**Publication status: preparation in progress; not yet published.** This is a
documentation and build-maintenance patch release. It preserves the encoding
behavior and security fixes in 1.5.0 and introduces no new encoder security fix.
Do not infer Maven Central availability from a successful build or a Git tag.

## Highlights and compatibility

- Clarify JavaScript encoding modes, output growth, and valid insertion
  boundaries in Javadocs, guides, and matching JSP/Jakarta descriptions
  ([#244](https://github.com/OWASP/owasp-java-encoder/pull/244)).
- Explain why general/block modes retain script-letter escapes, while Source
  mode already leaves the URL reported in
  [#243](https://github.com/OWASP/owasp-java-encoder/issues/243) unchanged.
- Distinguish JSON whole-string HTML embedding from JavaScript fragment
  protection, and explain empty input, JavaScript escapes, HTML character
  references, and surrounding-template requirements.
- Strengthen regression tests to check the entire parsed script text. Add
  opening-script tokenizer-state and invalid-boundary controls, documenting the
  Jsoup mixed-case limitation verified separately in Chrome.

No public API, encoded output, null/Unicode handling, or published runtime
dependency changes are introduced by this patch. Java 8 remains the minimum
runtime. Core retains no runtime dependencies; adapters retain their core and
container-provided API dependencies. Maven coordinates, servlet namespaces,
JPMS/automatic-module names, and OSGi identities are unchanged. Keep core and
adapter versions aligned when upgrading; no new encoding migration is required
from 1.5.0.

The [1.5.0 security corrections](1.5.0.md) remain in effect. Applications still
using older releases should follow that release's migration guidance and
[GHSA-g8p6-7r8f-qrpv](https://github.com/OWASP/owasp-java-encoder/security/advisories/GHSA-g8p6-7r8f-qrpv).

## Build maintenance

Already-merged maintenance since 1.5.0 updates the wrapper to Maven 3.10.0,
release-baseline tag discovery, reviewed build-plugin dependencies, isolated
Tomcat/Jasper test engines, Dependabot routing, and pinned Actions. The optional
Jakarta fixture's Jackson changes concern build tooling, not encoder runtime
dependencies. See [CHANGELOG.md](../CHANGELOG.md) for details.
