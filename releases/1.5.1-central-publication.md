**3.10.0** wrapper, macOS arm64, UTC, and the recorded source timestamp. The signed
clean-cache reactor passed **2,290 tests**. A separate fresh-cache Docker/browser
and packaged-WAR build passed **2,297 tests**. Both had zero failures, errors or
skips. All thirteen unsigned payloads matched two independent fresh source-export
builds byte for byte. Public API checks against 1.5.0 and the isolated Java 17
packaged consumers passed locally; 17 artifact-guard tests and effective-POM SCM
checks also passed. The three Javadoc JARs and library manifest identities were
inspected before publication.
